# Visual Studio Code

> An open source AI-enabled code editor site for developers, with multi-agent development and remote container support.

## Main

- [Visual Studio Code - The open source AI code editor | Your home for multi-agent development](https://code.visualstudio.com/): Visual Studio Code is a free, open source AI code editor. Build with AI agents that plan, code, and debug for you. Manage multi-agent workflows across environments on Linux, macOS, and Windows

## Features

- [Agents - Visual Studio Code](https://code.visualstudio.com/features/agents): Visual Studio Code is the open platform for AI agents — run GitHub Copilot, custom, and third-party agents in parallel, locally or in the cloud, with any model. Free with GitHub Copilot
